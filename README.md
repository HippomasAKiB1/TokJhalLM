# TokJhalLM

> BanglaBERT is bland. TokJhalLM has flavor.

TokJhalLM is a ~30–50M-parameter Bengali language model trained from scratch on consumer hardware, purpose-built for the language people actually use online: **code-mixed Banglish and regional dialects**.

Hardware envelope: 4GB VRAM · 8GB RAM · i5-12th gen CPU
